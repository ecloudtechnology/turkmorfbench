# Değişiklik kaydı · Changelog

## 3.8.0 — 2026-09-29 · birincil sürüm / primary release

Bu, TurkMorfBench'in dondurulmuş birincil sürümüdür: veri 466.517 madde (14 kova, çekirdek 1.836),
puanlama kuralı `harf` (karaktere bölünmüş log-olasılık), hücre kümeli güven aralıkları, altı kurallı
duyarlılık çözümlemesi, insan tavanı ölçümü ve 17 modellik liderlik tablosu (boyut ve TurkishMMLU
sütunlarıyla). Sonraki sürümler veri ya da puanlama kodunu değiştirirse yeni bir yayın sürümü numarası
alır ve önceki sürümün sayılarıyla karşılaştırılmaz.

This is the frozen primary release of TurkMorfBench: 466,517 items (14 buckets, 1,836-item core), the
`harf` scoring rule (character-normalised log-likelihood), cell-clustered confidence intervals, six-rule
sensitivity analysis, a human-ceiling measurement and a 17-model leaderboard (with size and TurkishMMLU
columns). Any later change to data or scoring code gets a new release number and is not compared with
figures from this one.
